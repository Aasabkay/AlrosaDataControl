# Фронтенд: сверка ИТ-активов

Простой интерфейс к API сверки: дашборд, загрузка источников, журнал импорта,
таблица ошибок с фильтрами, карточка актива с диффом и предпросмотр отчёта.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

По умолчанию интерфейс ходит на мок-API (`http://localhost:8000`, см.
`tools/mock_api.py`). Адрес меняется переменной окружения:

```bash
# файл frontend/.env
VITE_API_URL=http://localhost:8000
```

## Сборка

```bash
npm run build
```

Готовая сборка появляется в `frontend/dist` — её можно отдать любым
статическим сервером или позже встроить в FastAPI как статику.

## Структура

```
src/
  api.js          — единственная точка обращения к API (базовый адрес из env)
  App.jsx         — вкладки и переходы между экранами
  hooks/useApi.js — загрузка данных с состояниями loading/error
  components/ui.jsx — простые элементы: панели, бейджи, дифф значений
  pages/          — Дашборд, Загрузка, Журнал, Ошибки, Активы, Отчёт
```
